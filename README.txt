Esta PWA é um guia e portefólio interativo do Curso Técnico de Multimédia, feita em HTML, CSS e JavaScript com foco em telemóveis. A app funciona numa única página dividida em três partes principais: a Home, que apresenta o curso; a aba Anos, que mostra as disciplinas e módulos do 1º ao 3º ano através de filtros rápidos; e a Galeria, que exibe os trabalhos práticos dos alunos. Tecnicamente, inclui um ficheiro manifest.json que permite instalar o site como um aplicativo no ecrã do telemóvel e um Service Worker (sw.js) que guarda os dados em cache para garantir que toda a estrutura funcione perfeitamente mesmo quando o utilizador está sem internet (offline).
